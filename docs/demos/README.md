# Demonstração do VeloRent

Registros da execução do código original, compilado com Java 21 e Maven, com Hibernate e uma instância MySQL separada.

O vídeo de 30 segundos reúne imagens de trechos da saída real do console, com legendas e sem áudio. Menus repetidos foram omitidos; entradas, confirmações e resultados foram preservados. O GIF oferece uma prévia no README.

Fluxo executado:

1. Entrar e consultar os módulos da locadora.
2. Cadastrar e consultar um cliente fictício.
3. Cadastrar um Fiat Argo com diária de R$ 150.
4. Registrar disponibilidade para outubro de 2026.
5. Criar orçamento entre 5 e 9 de outubro: quatro dias, R$ 600.
6. Registrar e consultar o pagamento interno de R$ 600 via Pix.

Cliente, CPF, telefone, endereço, e-mail e placa são dados fictícios. O pagamento é um registro local; nenhuma cobrança ou transferência financeira foi realizada.

Para executar a aplicação, consulte o [README principal](../../README.md#como-executar).
